# Fitlog Website

FitLog is a workout tracker. You log your sessions (strength, cardio, flexibility), search and filter your history, edit or delete entries, and see your totals at a glance.

## Features

- Log workouts and training sessions
- Track progress over time
- View fitness statistics and activity history
- Manage personal fitness goals
- Responsive interface for desktop and mobile

# Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open the local address printed by the development server in your browser.

### Production Build

```bash
npm run build
npm run preview
```
